# Portafolio — Luissy Yhaimar Angulo Suárez

Portafolio personal de una sola página: desarrollo web y móvil, proyectos (Convertech · SENA y Portada Inmobiliaria) e integración de IA en el flujo de trabajo.

- **Stack del sitio:** HTML + CSS inline + JavaScript, sin build.
- **Animaciones:** reveals con IntersectionObserver, máscaras de texto en el hero, marquee, cursor personalizado, tilt 3D y barra de progreso.
- **Tipografía:** Instrument Serif, Space Grotesk, JetBrains Mono (Google Fonts).

## Uso

`index.html` es autocontenido: ábrelo en el navegador o publícalo tal cual.

## Publicar en GitHub Pages

1. Crea el repo (ej. `portafolio`) y sube estos archivos.
2. Settings → Pages → Source: `main` / carpeta raíz.
3. Queda en `https://<usuario>.github.io/portafolio`.
